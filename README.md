# -Spotify-customer-segmentation-and-churn-analysis-sql-project
Analyzed Spotify customer churn data using SQL to uncover engagement patterns, subscription performance, and retention insights through advanced querying techniques.

 Spotify Customer Segmentation and Churn Analysis SQL Project
 
 Project Overview
This project analyzes Spotify customer churn behavior and user engagement using SQL.

The analysis focuses on:
- Customer churn trends
- User engagement segmentation
- Subscription performance
- Device and country-wise analysis
- User activity patterns

Tools Used
- SQL
- MySQL
- Window Functions
- Aggregate Functions
- CASE Statements

 Key SQL Concepts Used
- GROUP BY
- ORDER BY
- CASE WHEN
- Window Functions
- RANK()
- NTILE()
- Aggregations
- Data Segmentation

 Business Insights Generated
- Identified churn-heavy customer segments
- Analyzed user engagement levels
- Compared subscription plan performance
- Ranked user activity categories
- Evaluated churn trends across countries and devices
